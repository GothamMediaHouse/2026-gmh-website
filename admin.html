Connect to your repository

Saved only in this browser, on this device — sent only to GitHub's API, nowhere else.
How do I get a token?
  1. On GitHub, go to Settings → Developer settings → Personal access tokens → Fine-grained tokens, then Generate new token.
  2. Give it a name like gallery admin, and under Repository access choose Only select repositories — pick just this site's repo.
  3. Under Permissions → Repository permissions, find Contents and set it to Read and write. Leave everything else as-is.
  4. Click Generate token, then copy it — GitHub only shows it once — and paste it above.
Scoping the token to just this one repo means that even if it ever leaked, it couldn't touch anything else in your GitHub account. Treat it like a password — don't share this page or paste the token anywhere else — and you can revoke it any time from that same Settings page.
